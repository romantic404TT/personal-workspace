# 个人工作台 · Nimbus（静态 Demo）

一个纯前端的"个人工作台"作品集 Demo：任务、日程、笔记、习惯打卡、数据洞察与一个 AI 聊天助手，全部使用本地 mock 数据，无后端、无真实 API。

## 技术栈

React 18 · TypeScript · Vite · Tailwind CSS · lucide-react · Recharts · Framer Motion

## 运行

```bash
npm install
npm run dev   # http://localhost:5173
```

## 诚实声明

- **AI 聊天为本地关键词脚本模拟**（`src/ai/engine.ts`），未接入任何真实大模型；但"任务卡 → 应用到今日待办 → 首屏同步高亮"的工作台数据联动是真实的。
- 所有人名、任务、日程均为虚构演示数据，会话内可变，刷新后重置。

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 工作台首页 | 时段问候 + 今日进度、概览四宫格、待办勾选联动、"现在"游标时间轴、AI 召唤卡、习惯打卡、迷你图表、快捷入口 |
| AI 抽屉 | ⌘J / 顶栏 / 召唤卡 / 任务 ✨ 四处入口；空状态、快捷指令、打字机流式、停止生成、错误重试、历史会话 |
| 命令面板 | Ctrl/Cmd + K 模糊搜索任务、笔记、页面 |
| 主题 | 深浅色切换（localStorage 持久化，首帧无闪烁） |
| 响应式 | 1440px 双栏 / 768px 折叠侧栏 + 底部 Tab / 375px 单列 |

## 架构要点

`src/data/mock.ts` 是唯一数据源，任务状态存于 `src/store/AppContext.tsx`，首页待办、任务页、命令面板、AI 生成的任务卡引用同一份数据（一处修改、多端同步）。

产品需求文档见 `docs/PRD-个人工作台.md`。
